# Max for Live 支持（实验性）

AIbleton 可以尝试读取和修改已加载设备向 Live 暴露的参数；实际可用参数由设备和 Extension Host 决定。

## 新建或编辑文件

告诉 AIbleton 要制作什么效果器或乐器。它会尝试自动查找本机 Live 的对应空白模板，并将新文件保存到 User Library 的 `AIbleton/Max Devices` 文件夹；同名时自动另起文件名。只有自动查找失败或你希望使用指定位置时，才需要提供路径。编辑现有设备时，工具先读取对象与连线，再将修改写入副本；不指定输出路径时会在源文件旁创建不重名的副本。请在 Max 或 Live 中打开并测试新文件，文件操作不会修改 Live 中已加载的实例。

目前仅支持简单 AMXD 容器及顶层对象：新增、删除、修改对象文本和位置，以及连接或断开连线。不要用于冻结设备；带已声明依赖或不支持的容器会报错。嵌套补丁和自定义控件暂不支持编辑。音频及 MIDI 接口、对象端口和声音效果仍需在 Max 中验证。

新建或编辑后会自动返回静态结构检查，已有设备也可以要求 AIbleton 检查。检查覆盖重复或缺失的对象 ID、部分已声明端口范围、参数范围、顶层图的左右声道可达性和部分视觉窗口设置；未识别的对象会标记为未验证。文件仍可能写入，即使检查报告错误，应按结果修正。图中存在路径不证明音频信号真的通过；嵌套补丁、对象是否实际存在、声音效果及窗口行为都需要在 Live/Max 中另行验证。

## 实时编辑已加载的设备

让 AIbleton 为目标设备准备 Max 桥接。它会返回一条 `js` 对象安装指令。在 Live 中打开该设备的 Max 编辑窗口，在目标补丁中加入该对象并保存；然后回到 AIbleton，告知安装完成。每个目标设备应使用自己的桥接目录。桥接文件存放于 `~/Documents/AIbleton/MaxBridges`，请勿在仍需使用桥接时移动或删除。

安装后可尝试列出对象、新增和删除对象、移动对象或连接和断开指定端口。现有对象必须有唯一的 Scripting Name 才能作为修改目标；当前检查不能列出连线。修改后在 Max 中检查并保存设备。发生超时后，操作可能已经执行，先检查实际补丁再重试。保持 Max 和桥接对象运行；无法连接时会报错。

桥接通过当前用户的本地文件交换消息；请保护桥接目录及设备文件。此功能尚未经过真实 Live/Max 的端到端验证，Max 版本、应用权限和运行环境可能影响其可用性。建议先在测试设备副本中使用，不要用于唯一的一份重要作品。
