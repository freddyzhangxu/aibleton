# 单任务试听建议设计

## 目标

确保每个任务执行回执最多显示一条试听建议，即使任务修改了多条轨道。

## 行为

- 所有 hint 先按任务聚合，而不是按轨道逐条输出。
- Scene 建议只出现一次。
- Arrangement 范围合并为最早起始至最晚结束，只出现一次。
- 建议 Solo 的轨道按首次出现顺序用“或”连接。
- A/B 建议最多出现一次。
- 中文示例：`试听：触发 Scene 或播放第 1–8 小节；建议 Solo Reggae Drums 或 Reggae Kick，并做 A/B 对比。`
- 没有任何有效 hint 时省略试听行。

## 实现与验收

- 用一个任务级汇总对象取代当前按轨道返回多个字符串的 `compactListenSummary()`。
- 现有 receipt 数据、服务端和历史 API 不变。
- Playwright 覆盖双轨同范围 + 双 Solo 的场景，断言只存在一条“试听”行且每个轨道仅出现一次。
- 全套单元测试与生产构建通过。
